Bangpypers organized August Devsprint in collaboration with [Pytorch India](https://bangalore.pytorchindia.org/), [Foss United bengaluru](https://fossunited.org/c/bengaluru) and [Point Blank](https://www.pointblank.club/), venue sponsored by [Amadeus labs](https://amadeus.com/en/bengaluru-labs-india).

We had few amazing maintainers joining us from different communities to make the event success

- [**Amogh Desai**](https://www.linkedin.com/in/amogh-desai-385141157/) — Apache Airflow
  Apache Airflow contributor working on tools and infrastructure that power modern data engineering workflows.
- [**Abhik Sarkar**](https://www.linkedin.com/in/abhiksark/) — Pythonlings
  Creator of Pythonlings, an interactive open-source project that helps developers learn Python by fixing small programs.
- [**Aayush Satyam**](https://github.com/ayushsatyam146) — PyTorch
  Open-source engineer contributing to PyTorch and the broader AI/ML ecosystem.
- [**Ganesh Kathiresan**](https://www.linkedin.com/in/ganesh-kathiresan/) — NumPy
  NumPy core developer and maintainer contributing to one of the foundational libraries of the Scientific Python ecosystem.
- [**Farhaan Bukhsh**](https://www.linkedin.com/in/farhaanbukhsh/) — OpenCraft
  Open-source engineer at OpenCraft and an active contributor to the Open edX ecosystem.
- [**Rajandran R**](https://www.linkedin.com/in/rajandranr/) — OpenAlgo
  Creator of OpenAlgo, building open-source tools for algorithmic trading and the developer community around it.
- [**Sumantro Mukherjee**](https://www.linkedin.com/in/sumantrom/) — PyTorch
  Open-source engineer working with the PyTorch ecosystem and actively involved in building and supporting developer communities.

By the end of event we recording 15+ PR that were open 5 PRs merged to completion, and few folks who were able to setup big projects like pytorch and airflow in there system to be dev ready.

I also met with few folks who made there first ever contribution in a github project and were really happy about it.
We want to thank the maintainers and partners in this event who helped support this event.

We will try to do another such event soon.! stay tuned.
