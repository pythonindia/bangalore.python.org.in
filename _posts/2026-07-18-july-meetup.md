The July Bangpypers meetup was hosted at [Paytm AI Office](https://www.linkedin.com/company/paytm/) in Bellandur, where we had some amazing talks on building cool long-running agents with langchain deepagents framework, a cool set of tricks with plumbum and how you can use it instead of bash, and an inthon language experiment for interacting with the system using natural language.

[Ankur Gupta](https://www.linkedin.com/in/ankurgupta1982/) started the event with an insightful talk about deepagents and how he built a "book authoring agent" which can generate books with realistic covers. He demonstrated his application and gave a walkthrough of how each component works.

![Building Long Running Agents with DeepAgents](https://secure.meetupstatic.com/photos/event/c/c/b/e/highres_535252414.webp "Building Long Running Agents with DeepAgents")

After this, [Suvarna Narayanan Baratharaj](https://www.linkedin.com/in/suvarna-narayanan-baratharaj-326b92212/) presented his practical learnings and experience in shifting from bash scripts to Python powered with uv and plumbum. He shared why he's bullish about the future of this powerful combination. His talk showcased the ability to remove boilerplate code.

![Forget bash! Harness python for the Command Line](https://secure.meetupstatic.com/photos/event/c/c/c/a/highres_535252426.webp "Forget bash! Harness python for the Command Line")

In the final talk, [Harsha](https://www.linkedin.com/in/techharva/) shared his journey, learnings, and roadmap for a unique project called Inthon. He is building a natural language for agents to interact with the system, built on top of Python.

![Inthon - The World's First Agent-Level Language Built on Python](https://secure.meetupstatic.com/photos/event/c/c/c/c/highres_535252428.webp "Inthon - The World's First Agent-Level Language Built on Python")

We also had two amazing lightning talks:

[Punita Ojha](https://www.linkedin.com/in/punita-ojha-74550a53/) delivered a lightning talk on *Spec Driven Development* and shared her journey of discovering and applying it to her personal project.


[Sameer Alam]() presented a lightning talk introducing Documentation site builder.
